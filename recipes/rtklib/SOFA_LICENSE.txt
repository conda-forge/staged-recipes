SOFA-derived code in RTKLIB-EX
==============================

The str2str executable in this package is built with src/sofa.c from
RTKLIB-EX, which uses routines and computations derived from software
provided by the IAU SOFA Board under the SOFA Software License reproduced
below. It does not itself constitute software provided by and/or endorsed
by SOFA.

src/sofa.c is a concatenation of the SOFA C library files epv00.c, s2pv.c,
obl06.c, pfw06.c, ir.c, rz.c, cp.c, rx.c, rxp.c, rxpv.c and moon98.c (SOFA
issue 2023-10-11), modified by RTKLIB-EX as follows: function arguments that
are not modified are declared const; static local variables and data that
were effectively constants are declared const; iauEpv00() and iauMoon98()
are renamed by removing the "iau" prefix; and the other supporting
functions are made static. The original SOFA files with their copyright
notices are distributed in the RTKLIB-EX source under lib/sofa/src/.

See http://www.iausofa.org for more information about SOFA.
